# AGENTS.md

This project is a React + Vite POC. A UI revamp to the Equifax India look is planned; the full handover is in
[`docs/ui-revamp/`](docs/ui-revamp/README.md).

If you are an agent assigned to the revamp:
1. Read `docs/ui-revamp/README.md`, then your brief in `docs/ui-revamp/agents/` (start with `00-shared-context.md`).
2. Stay inside the files your brief owns. Logic in `src/state`, `src/lib`, `src/services`, `src/data` is frozen (string-only copy edits excepted, see README).
3. Commands: `npm install`, `npm run dev` (http://localhost:5173, add `?recentReport=1` for the category view), `npm run build`.
4. No new dependencies. No gradients, pills, emoji or monospace fonts. Tokens only.
